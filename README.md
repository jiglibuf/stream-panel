# Пульт стрима

Планшет на держателе вместо цифрового блока: сцены, эфир, запись, повтор, звук — и всё это с телефона/планшета
в твоей домашней сети или в tailnet.

Состав: Python-сервис (aiohttp, порт 8090) — единственный, кто говорит с OBS через obs-websocket v5;
фронт (React + Vite, PWA) отдаётся тем же сервисом.

Статус: в разработке, v1 (сцены + транспорт). Звуковая панель — следующая итерация.

## Требования

- OBS Studio с включённым obs-websocket v5 (`Инструменты → Настройки WebSocket-сервера`, порт 4455).
- Python 3.12+ (для сервиса), Node 20+ (только для сборки фронта).
- Запущенный OBS — источник правды по состоянию; без него пульт показывает «OBS офлайн».

## Разработка

```bash
# тесты (быстрые, без OBS)
scripts/test.sh

# тесты против живого OBS (меняют состояние; короткий тестовый эфир разрешён)
scripts/test.sh --live
```

## Структура

```
server/     сервис: клиент OBS, состояние, команды, HTTP/WS API
frontend/   React + Vite пульт (PWA)
tests/      pytest: unit + интеграционные против фейкового obs-websocket
scripts/    запуск и тесты
```
