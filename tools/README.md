# tools — установка и запуск

Короткие скрипты, которыми владелец поднимает и гасит систему. Все рассчитаны на
запуск от обычного пользователя: юниты — пользовательские, sudo не нужен.

| Скрипт | Что делает |
|--------|------------|
| `install.sh` | Окружение Python (`.venv`, aiohttp), сборка фронта (если нужна), каталог конфига, юниты в `~/.config/systemd/user`. Идемпотентен, юниты по умолчанию не включает. |
| `panel.sh` | `up` / `down` / `restart` / `status` для пульта и подключённых модулей (чат, звук, аналитика, сетка, каст, хаб). |
| `game-mode.sh` | `on` / `off` / `status`: «режим игры» — гасит стрим-стек и выгружает локальную модель, освобождая VRAM. Только останавливает, ничего не удаляет; `off` возвращает как было. |

## Порядок первого запуска

```bash
tools/install.sh                 # окружение, фронт, юниты, каталог конфига
tools/panel.sh up                # поднять пульт
tools/panel.sh status            # убедиться, что всё на месте
```

Модули поднимаются по мере надобности: `tools/panel.sh up chat mix analytics` или
`tools/panel.sh up all` (пульт + всё установленное + хаб MediaMTX).

## Режим игры

Перед игрой, чтобы освободить видеопамять:

```bash
tools/game-mode.sh on            # гасит стрим-стек, печатает освободившуюся VRAM
tools/game-mode.sh off           # возвращает ровно то, что было выключено
```

`on` останавливает службы и контейнеры (`docker stop`, не `rm`) и выгружает
загруженную модель Ollama. Список того, что было остановлено, лежит в
`~/.local/state/stream-panel/game-mode.state`; `off` читает его и поднимает всё
обратно. OBS и пульт скрипт не трогает.

## Проверки

```bash
bash -n tools/*.sh                       # синтаксис
systemd-analyze --user verify deploy/systemd/*.service
tools/panel.sh status
```
